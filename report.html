1. Resumen / Función del proyecto

Este proyecto es una aplicación web para registro contable y gestión comercial: llevar el libro diario, gestionar proformas y pedidos, controlar deudas (cuentas por cobrar / pagar), y realizar arqueos de caja. La UI permite registrar órdenes de trabajo (work_orders), manejar adelantos, abonos parciales y generar asientos contables que representan movimientos reales de caja.

2. Qué hará la aplicación (funcionalidades clave)

  • Registro de asientos contables diarios (Libro diario: ingresos y egresos).
  • Gestión de pedidos / work orders con items y adelantos.
  • Proformas (cotizaciones) y conversión a ventas.
  • Gestión de Deudas: creación de cuentas por cobrar/pagar y registro de abonos parciales.
  • Arqueo de caja: cierre de caja y resumen ejecutivo con conteo por denominaciones.
  • Historial de movimientos con auditoría y detalle de asientos.
  • Soporte offline-simulado: adaptador localStorage para demo si no hay Supabase configurado.
  • Exportación CSV, copiador al portapapeles y soporte básico de voz (Web Speech API) para dictado de asientos.

6. Cómo probar / poner en marcha (rápido)

npm install
npm run dev    # abre http://localhost:5173

Para usar Supabase:
- Crear proyecto en supabase.com
- Ejecutar las migraciones en orden desde supabase/migrations/
- (Opcional) Ejecutar supabase/seed.sql
- Pegar VITE_SUPABASE_URL y VITE_SUPABASE_ANON_KEY en .env.local
- Reiniciar npm run dev
